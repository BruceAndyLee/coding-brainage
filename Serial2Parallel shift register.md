Устройство, у которого есть несколько output-пинов для подачи сигнала на управляемые устройства.

Данные, которые необходимо отобразить, записываются на устройство последовательно с помощью трёх основных пинов:
- clock - для задания тактов. Управляющее устройство может задать частоту дискретизации.
- latch pin - нужно подать положительный сигнал, чтобы регистр начал записывать значение
- serial data input - пин, с которого считываются и запоминаются биты (в соответствии с управляющим clock-сигналом)
