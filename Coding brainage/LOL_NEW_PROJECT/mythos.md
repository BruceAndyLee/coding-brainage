Идея проекта: psql база данных с визуализацией всех родственных связей греческих богов, полубогов и героев
Основные пункты:
- продумать простую но расшряемую модель данных
- завести таблицы и ограничения
- описать пользовательские сценарии добавления и просмотра данных
- реализовать их с помощью расширений postgres, подготовить БД к работе с ней
- заполнить её перечитывая книжки Стивена Фрая
Цель:
- реализовать знакомые сценарии работы с помощью нового инструмента
- создать себе приложение, которым мне хочется пользоваться для себя
