Идея проекта: код, который генерит деревья для красоты или для сидов в plm
Основные пункты
- описать типы, которые будут в системе
- написать генератор дерева конкретной высоты
- добавить отдельный слой логики для обработки листьев дерева
- добавить отдельный слой логики для разделения дерева на группы узлов
- написать простую визуализацию в терминале
Цель: написать ядро, которое генерит деревья по стохастической L-системе, придумать для него слой визуализации с помощью svg или чего-то системного.
В первую очередь деревья должны содержать интересные данные, во вторую очередь - красиво отрисовываться.
