Чтобы интегрировать [[STACK]] в компуктер, нужно:
- выделить один регистр, который будет управлять стеком
- класть в него нужный байт, который будет декодироваться как флаг "положить в стек" или "считать из стека"
- в LEG-архитектуре один и тот же регистр используется для обращения к памяти и к стеку

```toml
r5 values

xxxx 0001 # read from RAM
xxxx 0010 # write to RAM
xxxx 0100 # pop from stack
xxxx 1000 # push to stack
```
