Собрать схему, которая принимает два управляющих битовых сигнала:
- pop
- push
и один сигнал с 8ми-битным значением, которое нужно положить в стек.

При подаче управляющего сигнала значение должно складываться в стек или выдаваться из него сразу.

Попытка расписать логику:
```toml
# one line is one logical tick

| push  | pop   | prev action out | used address | remembered address |
| ---   | ---   | ---             | ---          | ---                |
| +     | -     |                 | 0            | 1                  |
| -     | -     | push            | 1            | 1                  | // no action
| -     | -     | push            | 1            | 1                  | // no action
| +     | -     | push            | 1 = r        | 2                  |
| -     | -     | push            | 2            | 2                  | // no action
| +     | -     | push            | 2 = r        | 3                  | // push
| -     | -     | push            | 3            | 3                  | // no action
| -     | +     | push            | 2 = r - 1    | 2                  | // pop
| -     | +     | pop             | 1 = r - 1    | 1                  |
| +     | +     | pop             |              | 1                  | // push + pop
```

Идея решения нашлась внезапно писец:
- строим контур, который берет последний запомненный адрес и перезаписывает его на следующую итерацию так:
	- если был сигнал `pop`, то адрес уменьшается на один
	- если был сигнал `push`, то адрес увеличивается на один
- понадобилась модификация: если подается сигнал `pop`, то посчитанный уменьшенный адрес применяется СРАЗУ (регистр, в котором хранится последний адрес, выдаст обновленный адрес только на следующей итерации, и это важный момент, потому что иначе бы не работала бы логика push - значение записывалось бы сразу в следующий адрес а не в текущий)
