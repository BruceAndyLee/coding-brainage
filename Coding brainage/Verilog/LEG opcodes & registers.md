В этой архитектуре процессора предполагается работа с процессорными словами.
Одно слово занимает 4 байта и имеет следующую структуру:
```toml
0000 0000 # opcode
0000 0000 # operand 1
0000 0000 # operand 2
0000 0000 # output destination
```

Детализация каждого байта
```toml
## 1. opcode
0000 0000 # ADD
0000 0001 # SUB 
0000 0010 # AND 
0000 0011 # OR
0000 0100 # NOT
0000 0101 # XOR

xx01 0000 # 32 if eq
xx01 0001 # 33 if neq
xx01 0010 # 34 if l
xx01 0011 # 35 if leqe
xx01 0100 # 36 if g
xx01 0101 # 37 if geq

1xxx xxxx # первый операнд интерпретируется как immediate value вместо дефолтной адресации (см. ниже)
x1xx 0xxx # второй аргумент интерпретируется как immediate value вместо дефолтной адресации регистров, счетчика и инпута

## 2. operand 1
# этот байт указывает откуда взять значение первого операнда
0000 0000 # reg0
0000 0001 # reg1
0000 0010 # **reg2**
0000 0011 # reg3
0000 0100 # reg4
0000 0101 # reg5
0000 0110 # counter
0000 0111 # input

## 3. operand 2
# этот байт указывает откуда взять значение второго операнда аналогичным образом
0000 0000 # reg0
0000 0001 # reg1
0000 0010 # reg2
0000 0011 # reg3
0000 0100 # reg4
0000 0101 # reg5
0000 0110 # counter
0000 0111 # input

## 4. write address
# этот байт указывает куда должен быть направлен результат действия в этом такте
# в один из регистров или на вывод
0000 0000 # reg0
0000 0001 # reg1
0000 0010 # reg2
0000 0011 # reg3
0000 0100 # reg4
0000 0101 # counter
0000 0110 # output
# если opcode был логическим оператором, то это адрес, на который надо переключить счетчик
xxxx xxxx # 
```

```toml
r0 - general purpose & RAM addressing
r1 - general purpose & STACK/RAM value
r2 - general purpose
r3 - general purpose
r4 - general purpose
r5 - RAM & STACK enable flagsa
```
