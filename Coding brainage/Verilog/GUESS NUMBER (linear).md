Задача в том, чтобы подобрать число от 0 до 255.
- на вход подается 0 (последнее выведенное число меньше либо равно нужному) или 1 (выведенное число больше нужного)
- нужно вывести нужное число

Решение: начиная с ноля выводить байт на выход и проверять инпут, если на него прилетает 0, то увеличивать число на один и выводить его снова
- определить начало программы, к которому код будет возвращаться после проверки условия
- записать число 1 в регистр общего назначения R2 - это будет инкремент после неудачной попытки
- записать число 0 в регистр R1 - это будет значение для первой попытки. К нему же будет добавляться 1 каждый раз
- *здесь начинается цикл*
- вывести число из регистра R1 в output
- сложить R1 и R2 (это инкремент)
- перенести результат сложения (R3) в R1
- сохранить input в R3 - это проверка выхода из цикла
- выполнить сравнение с нулем `eq 0` (R3 сравнивается с нулем)
- при выполнении условия прыгаем на "*здесь начинается цикл*"

Реализация на своих собственных asm-командах
```asm
1
cpy | r0 | r2d # incremet to r2
0
cpy | r0 | r1d # init val to r1
0 # where to jump
cpy | r1s | out
cpy | in | r3d # check !=0
neq0
add
cpy | r3s | r1d # next att. to r1
5
alw
```
loop is identical to writing a plain number bc it means writing an immediate value to R0
