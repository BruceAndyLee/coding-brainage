Идея проекта: документация линукса на примере alpine
Основные пункты:
- загрузка
- управление сервисами
- управление пакетами
- установка и удаление драйверов
- назначение папок
Цель: иметь в голове граф зависимостей между папками, процессами и конфигами в работающем инстансе Alpine OS, чтобы ориантироваться в конкретных проблемах, которые требуют знания ОС (работа с флешками, работа с файловыми системами, установка и запуск DAYM-онов)
