Это ручка, которая ответственна за чтение .ko файлов (ELF-формат).
С её помощью можно декларативно загружать драйверы в ОС, чтобы подсистемы умели работать с девайсами определенных типов.
Определяет зависимости подгружаемого модуля.

- user-space: эту утилиту можно вызывать скриптами для загрузки драйверов
- kernel-space: может быть вызвана ядром, когда подсистема соединилась с девайсом через шину, и для этого девайса не загружен драйвер (но при этом драйвер доступен в системе /lib/modules/.../module.aliases)
