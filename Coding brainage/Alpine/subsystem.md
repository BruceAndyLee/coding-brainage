Подсистема - это какой-то лютый код, достаточно абстрактный. Его задача - выдать драйверам интерфейс для программного управления любым оборудованием на машине.

Подсистемы могут быть встроены в ядро, а могут подключаться к нему на этапе компиляции(?) из файлов с раширением `.ko` (kernel object?)

Примеры подсистем:

| subsystem  | отдельный файл с модулем | чем управляет                                                                           | где найти артефакты работы подистемы |
| ---------- | ------------------------ | --------------------------------------------------------------------------------------- | ------------------------------------ |
| block      | \<built-in\>             | "блоковые"? устройства                                                                  | /dev/sdX, /dev/mmcblkX               |
| TTY/serial | \<built-in\>             |                                                                                         | /dev/videoX                          |
| network    | \<built-in\>             |                                                                                         |                                      |
| v4l2       | `videodev.ko`            |                                                                                         |                                      |
| IIO        |                          | АЦП ЦАП                                                                                 |                                      |
| USB        | usbcore.ko               | подключение USB девайсов, соотнесение девайса с драйвером, которому передать управление |                                      |
|            |                          |                                                                                         |                                      |
