Из каких компонентов собирается удобный манипулятор 3д сценой:
- глаз/камера с параметрами:
	- FOV - градусы
	- aspect ratio
	- view frustum - пирамида взгляда обрезается спереди и сзади ближней и дальней плоскостями. Всё, что находится ближе к камере, чем ближняя плоскость, не рендерится, так как считается помещенным ЗА наблюдателя или, при плохой детекции коллизиий, В наблюдателя.
	  Дальняя плоскость в основном нужна для ограничения дальности видимости. Если сцена не загружена, дальнюю плоскость можно поместить бесконечно далеко.
- точечный источник света
- эмбиентное освещение сцены (свет, который распространяется во всех направлениях в объеме сцены)
- контроллер ориентации камеры:
	- перетаскиванием меняются углы наклона камеры (рыскание и тангаж)
	- прокручиванием меняется положение камеры вдоль направления вперед и назад
	- прокручивание с зажатой клавишей - управление углом крена
- отрисовка геометрии с тонкой настройкой поверхности:
	- вершины и/или ребра проволочного каркаса, аппроксимирующие произвольную геометрию 3Д-модельки
	- положение в пространстве - три числа
	- поворот в пространстве - три числа
	- материал - проволочный каркас или поверхность некоторого цвета
	- текстура - развернутая картинка, которая натягивается на проволочный каркас
	- карта нормалей - дополнительная текстура, которая указывает, как именно ориентирована поверхность в каждой точке, чтобы свет отражался в разной степени от разных участков геометрического объекта. Это создает эффект объемной и детализированной поверхности без увеличения количества полигонов в проволочном каркасе
	- шейдер - кастомный алгоритм вычисления цвета, применяется для генерации произвольных эффектов при отрисовке некоторой поверхности

## Сцена

```js

const scene = new THREE.scene();

const camera = new THREE.camera(
	75, // fov
	win.innerWidth / win.innerHeight, // aspect ratio
	0.1, // frustum near plane
	1000, // frustum far plane
)

const renderer = new THREE.WebGLRenderer();
```

## Геометрические объекты
```js

function gen_icosahedron(scene: THREE.Scene) {
	// this is pure vector stuff, from which to generate polygons
	const geometry = new THREE.Icosahedron(2); // 2 is the radius
	const material = new THREE.MeshBasicMaterial({ color: "#223344", wire: true });
	const res = new THREE.Mesh(geometry, material);
	scene.add(res)
	return res;
}
```

Чтобы штука геометрическая штука реагировала на освещение, надо заменить материал с basic на standard:
```js
const material = new THREE.MeshStandardMaterial({ color: "#223344" });
```

## Освещение
Добавление точечного источника
```js
const point_light = new THREE.PointLight(
	0xFFFFFF,
	100, // luminosity
);
scene.add(point_light);
```

Добавление эмбиентного освещения:
```js
const ambient_light = new THREE.AmbientLight(0xFFFFFF);
scene.add(ambient_light);
```
