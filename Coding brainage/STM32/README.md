Идея проекта: научиться работать с платой с STM микропроцессором
Основные пункты:
- разрисовать и объяснить архитектуру платы
- понять как подключаются и конфигурируются периферийные устройства
- понять как работают загрузчики
Цель
- понимать, какие есть сложности в разработке встроенных систем
- понимать как читать спецификацию и ставить задачи разработчикам
- говорить с разработчиками на одном языке
