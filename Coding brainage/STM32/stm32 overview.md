Основной смысл работы микроконтроллера: обработка прерываний.

Какие виды прерываний обрабатывает MCU:
- периферийное устройство подняло готово передать данные о сигнале
- система (OS или просто один единственный цикл) запросила обработать очередную итерацию - в `while(1)` цикле

Прерывания выстраиваются в иерархию.
Появление прерывания с более высоким приоритетом может приостановить обработку прерывания с низким приоритетом.
Иерархию во многом настраивает разработчик приложения.

Для работы с периферией у микроконтроллера есть шины.

Для настройки пользовательских вызовов по прерываниям разного характера, в микроконтроллере есть [[NVIC]]. У этой штуки есть много проводов на вход. Сигнал с каждого провода может быть обработан как прерывание с конкретным пользовательским обработчиком и приоритетом.
