Как vue обновляет компоненты.
- в какой-то момент вызывается функция вида `() => h("div", [/* children rendering */])`
	- рендеринг детей может быть завязан как на компоненты, так и на отдельные элементы в DOM
- во время её первого запуска она регистрируется как зависимость на все рефы и компутеды
	- то есть, при изменении ЛЮБОГО свойства в состоянии компонента функция h для всего компонента будет запущена
	  (представьте, что у вас 100 форм, по 100 полей в каждом...)
- во время выполнения повторного рендеринга, внутри функции `h` 
- полученное виртуальное дерево сравнивается с тем, которое хранится в кеше с предыдущего рендеринга и измененные узлы коммитятся в DOM - это то самое место о котором можно краем уха услышать в видосах, которые говорят мол вот фреймворк с виртуальным деревом - полная фигня, медленно, bloat
	- альтернатива, разумеется, писать эффекты таким образом, чтобы скипать рендеринг всего, чью зависимости не изменились
- рендерить совсем уж все узлы конечно было бы не очень здорово, поэтому у vue есть функция `shouldUpdateComponent`
	- для дочернего компонента НЕ рендерится новый VNode, если vue видит, что ссылки на первом уровне в объекте `props` не поменялись. Это по сути shallowCompare
	  Разумеется, так же проверяется, что в пропах всё еще то же самое количество свойств, что и было раньше
- крайние случаи
	- если у закешированного состояния пропы были null-ish, то перерендерится он только в случае, если они теперь не nullish. То есть, например, когда vnode рендерится впервые
	- если у закешированного состояния пропы были, а у нового стали nullish - то VNode так же рендерится заново.

Вся эта логика справедлива как для дочерних vue-компонентов, так и для VNode-узлов, которые существуют только в рамках одного компонента и привязаны к реактивному состоянию.
И то и другое рендерится функцией `h`, которая возвращает `VNode`:
```js
const email = ref("");
const username = ref("");
return () => h("div", [
	h("div", { innerText: email.value }),
	h("div", { innerText: username.value })
])
```

Аналог в шаблоне компонента:
```html
<template>
	<div>
		<div>{{ email }}</div>
		<div>{{ username }}</div>
	</div>
</template>
```
