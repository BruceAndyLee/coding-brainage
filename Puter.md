TЧтобы система была компухтером, надо уметь несколько вещей:
- нужен блок арифметики (побитовые NAND, AND, NOR, OR, SUM, SUB)
- нужен контур с несколькими регистрами (минимум 6?), который должен уметь
	- переносить значения из одного регистра в другой
	- из байтового ввода в регистр
	- из регистра в байтовый вывод
- нужен контур реализующий счетчик - для итерирования по адресному пространству с командами программы
- нужен контур для проверки условий (больше, меньше, равно нулю)
- нужна дополнительная обвязка вокруг контура с регистрами, которая умеет переключаться между 4мя режимами:
	- перенос данных между регистрами/инпутом/аутпутом (дефолтный режим работы контура регистров)
	- вычислительный режим - два байта, предварительно записанные в два регистра, пропускаются через блок арифметики и результат действия складывается в третий регистр
	- режим сравнения - байт, предварительно записанный в регистр, проверяется на одно из восьми условий. При выполнении условия, счетчик команд переписывается на значение, предварительно сохраненное в отдельном регистре
	- режим немедленной записи в память (хз, зачем он нужен???) - в этом режиме 6 битов команды являющиеся её полезной нагрузкой, записываются в предназначенный для таких случаев регистр.
