Два байтовых входа:
- первый - для числа, которое так или иначе сравнивается с нулем
- второй - для указания команды
	- GTE
	- GT
	- EQ
	- NEQ
	- LT 0
	- LTE 0
	- ALWAYS
	- NEVER

Интеграция в схему с адресуемыми регистрами
- в регистр R0 предварительно записывается адрес для перехода
- в регистр R3 предварительно записывается число
- на следующем тике активируется контур с логическим юнитом, на вход ему подается команда и бит данных
- если указанное условие выполнено, значение из R0 подается на вход в счетчик программы и перезаписывает адрес текущей выполняемой инструкции
